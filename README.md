# Turn Timer / 回合钟

A bilingual, two-player board game timer for one shared device. Main time and overtime per turn are configurable. Once main time runs out, each turn receives a fresh overtime allowance; reaching zero automatically switches to the opponent.

简体中文与英文界面；支持基础时间、回合时限、暂停、继续与重置。
